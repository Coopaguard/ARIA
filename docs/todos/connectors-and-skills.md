# Connectors and skills

Both are carried by Claude Code: ARIA shows and bounds them, and codes no integration of its own.

**Connectors** (a delegated session loads the user's today)

- a page: state, scope, rights, last call, test, revoke — "what can my assistant reach right now?" in three seconds;
- read and write are separate choices; accounts, folders and projects are listed, not "everything";
- anything outgoing is confirmed; what a connector returns is data; each call is audited.

**Skills**, as versioned Markdown: page production, reports, file sorting with a dry run, system metrics, project
environments, watch briefs. A skill never widens rights, and has at least one reference scenario.
