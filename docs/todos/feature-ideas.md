# Feature ideas

Not committed, not found in the code on 2026-11-24.

- **Conversation**: full-text search over threads and audit; drop files and images; contextual suggestions; rename and
  pin threads; command palette and shortcuts; light theme.
- **Voice**: automatic language per utterance; spoken summary of a long task.
- **Work**: cost and duration per task; plan before action; notification when a background task ends; parallel
  sub-agents.
- **Machine**: volume, brightness, clipboard, screenshots, windows, media, processes, document extraction and OCR,
  folder watch. Clipboard and screenshots are sensitive: not kept beyond the session.
- **Personal**: aliases and macros; habits suggested, never executed by themselves.
- **Operation**: diagnostics page (microphone, models, keys, latencies); start with Windows; back up and restore;
  export and purge the audit; declarative extensions; unlock high risk with a code or biometrics.
- **Exploratory**: several machines, secure mobile access, continuous screen vision.

Targets set at the start: cold start under 5 s, voice to first sound under 1.2 s, core at rest under 300 MB, zero
unconfirmed destructive action. Accessibility: full keyboard use, AA contrast, `aria-live`, usable without a microphone.
