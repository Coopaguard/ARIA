# Cadence: scheduled tasks and watch

ARIA works without being asked. No code yet; `dontAsk` is reserved for these sessions.

**Rhythms**: time, interval, event (a file arrives, a repository changes), window. **First ones**: morning brief,
topic watch, machine health, folder tidying, project state, memory consolidation, weekly review.

**Nobody is there to confirm**, so:

1. read-only by default, never high risk: nothing deleted, pushed, sent or published;
2. side effects are **prepared, not executed**: a plan to apply with one click;
3. paths, connectors and tools are declared by the cadence, not inherited from the profile;
4. limits on duration, cost and steps; beyond, stop and leave a trace;
5. audited as `cadence:<id>`;
6. collected content triggers nothing;
7. one global switch, and one per cadence.

**Against noise**: deduplicate, rate the signal, stay **silent when nothing matters**, one notification per cadence,
and "not interested" adjusts the topic.

**Output**: a page, a memory entry, a notification if it matters, spoken on demand. A Cadences page shows the next
and last run, cost, a switch and "run now". Creating one from the conversation asks for a summary to validate.
Later: event triggers, and catching up after the machine was off.
